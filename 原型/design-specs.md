# EventHub 卡片组件视觉样式规范

## 1. 设计理念

### 1.1 核心原则
- **毛玻璃效果（Glassmorphism）**: 采用半透明模糊背景，营造轻盈通透的视觉质感
- **背景友好**: 卡片设计确保不会干扰背景视频或动态效果的展示
- **优雅交互**: 默认隐藏操作控件，悬浮时优雅呈现
- **和谐配色**: 避免蓝紫色系AI风格配色，采用自然柔和的色调系统

### 1.2 设计目标
- 视觉层次清晰，信息层级分明
- 交互反馈及时，用户体验流畅
- 响应式适配，多设备兼容
- 性能优化，避免过度渲染

### 2.3 毛玻璃效果参数

```css

.glass-effect {

    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px);
    border: 1px solid rgba(255, 255, 255, 0.3);
}

/* 深色毛玻璃效果（适用于深色背景）*/
.glass-effect-dark {
    background: rgba(45, 55, 72, 0.7);
    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px);
    border: 1px solid rgba(255, 255, 255, 0.1);
}
```

## 4. 组件规范

### 4.1 统计卡片（Stat Card）

**结构**:
- 图标区域（顶部）
- 数值显示（中部）
- 标签文字（底部）

**样式**:
- 背景：毛玻璃效果
- 图标：48px × 48px，主色调
- 数值：24px，字重600
- 标签：14px，次要文字色

**交互状态**:
- 默认：阴影层级1
- 悬浮：阴影层级2，轻微上浮（4px），操作按钮渐显

### 4.2 事件卡片（Event Card）

**结构**:
- 顶部横幅区域（120px高度）
- 内容区域（标题、描述、时间地点）
- 底部操作区域（默认隐藏）

**样式**:
- 横幅：渐变色背景（主色 → 浅主色）
- 标题：18px，字重600，最多2行
- 描述：14px，次要文字色，最多3行
- 元信息：12px，弱化文字色

**交互状态**:
- 默认：阴影层级1，操作区域透明度0
- 悬浮：阴影层级3，上浮8px，操作区域透明度100%

### 4.3 社区卡片（Community Card）

**结构**:
- 顶部横幅区域（100px高度）
- Logo区域（圆形，80px直径，居中悬浮于横幅下方）
- 内容区域（名称、描述、成员数）
- 底部操作区域（默认隐藏）

**样式**:
- 横幅：渐变色背景
- Logo：圆形，白色边框（4px）
- 名称：18px，字重600
- 描述：14px，次要文字色，最多2行

**交互状态**:
- 默认：阴影层级1，顶部装饰条显示，操作区域隐藏
- 悬浮：阴影层级3，上浮8px，操作区域滑入显示

### 4.4 列表卡片（List Card）

**结构**:
- 左侧图标/头像区域
- 中部内容区域（标题、描述）
- 右侧操作区域（默认隐藏）

**样式**:
- 整体：左侧对齐，高度自适应
- 图标：40px × 40px，圆角8px
- 标题：16px，字重500
- 描述：13px，次要文字色

**交互状态**:
- 默认：背景透明，右侧操作区域宽度0
- 悬浮：背景色变浅，右侧操作区域展开

## 6. 交互动画规范

### 6.1 过渡效果

| 过渡类型 | 持续时间 | 缓动函数 |
|---------|---------|---------|
| 悬浮效果 | 300ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 操作按钮显示 | 200ms | ease-out |
| 卡片位移 | 300ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 透明度变化 | 200ms | ease-in-out |

### 6.2 状态反馈

| 状态 | 视觉反馈 |
|-----|---------|
| 悬浮 | 阴影增强、卡片上浮、操作按钮渐显 |
| 按下 | 卡片轻微下沉（-2px）、背景色加深 |
| 禁用 | 整体透明度50%、鼠标指针禁用 |
| 选中 | 边框高亮、背景色变化 |

## 8. 性能优化建议

### 8.1 毛玻璃性能优化

1. **限制模糊范围**: 避免对大面积元素应用backdrop-filter
2. **硬件加速**: 使用transform: translateZ(0)触发GPU加速
3. **合理降级**: 对不支持backdrop-filter的浏览器提供纯色背景降级

### 8.2 动画性能优化

1. **使用transform替代position**: transform属性触发GPU加速
2. **避免重排**: 动画尽量使用opacity和transform属性
3. **will-change优化**: 对即将动画的元素添加will-change属性

### 9.2 降级方案

```css

    }
}
```
